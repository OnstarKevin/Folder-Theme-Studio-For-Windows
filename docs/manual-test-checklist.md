# Beta4 人工测试清单

- [ ] Windows 10/11 x64 安装、启动、卸载；分别验证已安装和未安装 .NET 8 Desktop Runtime 的环境。
- [ ] 首次启动显示五步教程；完成或跳过后不再自动显示，顶部按钮仍可重新打开。
- [ ] 顶部“使用教程”和“设置”在最小窗口宽度及 100%、150%、200% DPI 下保持可用。
- [ ] 简体中文与 English 切换会更新已打开的主窗口，并在重启后保持。
- [ ] 四个颜色角色均可使用 HSV、十六进制、推荐色和最近颜色；保存更新预览，取消不改变原值。
- [ ] 新文件夹魔法棒 Logo 出现在窗口、任务栏、EXE、安装器和 README。
- [ ] 在一次性普通目录验证兼容模式的计划、应用、Explorer 刷新和恢复。
- [ ] 验证特殊文件夹、已有自定义 `Desktop.ini`、网络路径、重解析点及不可写目录被跳过。
- [ ] 验证全局模式只修改当前用户映射，恢复后回到应用前状态。
- [ ] 使用 SHA-256 文件核对安装包和源码包；确认安装包小于 25 MiB。
- [ ] 在“文件夹分类卡片”中创建、修改、重启后查看并删除一条分类；中英文界面均检查状态提示。
- [ ] 在资源管理器详细信息、大图标视图中悬停已分类文件夹约半秒，确认卡片内容、颜色和位置；移动鼠标后卡片及时消失。
- [ ] 在用户桌面和公共桌面的真实文件夹上悬停，确认卡片固定在文件夹旁；同名双路径、快捷方式和普通文件不触发。
- [ ] 在桌面与资源管理器分别用 Alt＋右键快速打开编辑窗口；改用自定义修饰键＋中键再试。未识别目标时原生右键菜单保持可用。
- [ ] 检查双色渐变调色板、全局不透明度（含 0% 和 100%）和 DIY 面板加速滚动；嵌套列表与文本框滚动不应被外层抢走。
- [ ] 确认未分类文件夹、文件、导航树项目和其他应用窗口均不显示卡片；主窗口收起到托盘及登录后台启动时监控仍可用。
