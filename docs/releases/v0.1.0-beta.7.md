# Folder Theme Studio v0.1.0-beta.7

## 新增

- 自定义图片图标现支持 ICO，并继续支持 PNG、JPG、JPEG 和 BMP。
- 多尺寸 ICO 会自动选用最大分辨率图层；同尺寸时优先高色深图层。
- ICO 的透明通道会保留，并统一生成软件需要的多尺寸 Windows 文件夹图标。

## 兼容性

- GIF、CUR、损坏文件和扩展名与内容不一致的图像仍会被拒绝。
- 递归监控、系统托盘、登录后后台启动以及恢复流程保持不变。

## 安装

运行 `FolderThemeStudio-v0.1.0-beta.7-setup.exe`。缺少 x64 .NET 8 Desktop Runtime 时，安装器会联网下载并安装。

本版本尚未签名，请核对随附的 SHA-256 校验文件。
