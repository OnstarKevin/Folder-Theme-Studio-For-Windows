# Folder Theme Studio v0.1.0-beta.8

## 新增

- 为桌面和资源管理器中的真实文件夹提供悬浮分类卡片，可设置分类、备注与双色渐变强调色。
- 在软件中集中管理文件夹分类信息；分类不修改文件夹中的内容。
- 默认 Alt＋鼠标右键可快速打开同款编辑窗口，支持自定义修饰键与右键／中键组合。
- 卡片在文件夹旁固定显示，所有卡片共用一个可调不透明度；DIY 面板的滚轮移动距离加倍。

## 安装

运行 `FolderThemeStudio-v0.1.0-beta.8-setup.exe`，可覆盖安装同一软件的旧版。缺少 x64 .NET 8 Desktop Runtime 时，安装器会联网下载并安装。

本版本尚未签名，请核对随附的 SHA-256 校验文件。悬浮卡片的实际显示效果需在 Windows 桌面和资源管理器中人工检查。
