# Folder Theme Studio v0.1.0-beta.5

## 新增

- 主窗口新增真正的二维可视化调色板，可直接用鼠标选择色相、饱和度和亮度。
- 新增独立的图片图标模式，支持 PNG、JPG、JPEG 和 BMP。
- 导入图片保持原始比例、自动居中，并使用透明边距补成方形图标。
- 内置样式与图片导入清晰分区，设置窗口保留通用设置。

## 修复

- 计算和应用方案会使用当前明确选择的图标来源。
- 导入失败不会覆盖之前的有效选择。
- 未选择图片时不会误用旧预览或允许计算方案。

## 安装

运行 `FolderThemeStudio-v0.1.0-beta.5-setup.exe`。安装器会在需要时联网安装 x64 .NET 8 Desktop Runtime。

本版本未签名，请核对随附的 SHA-256 校验文件。
