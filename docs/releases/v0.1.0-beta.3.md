# Folder Theme Studio v0.1.0-beta.3

Beta 3 修复了双击程序后窗口立即崩溃的问题，并改用轻量在线安装器。

## 本版修复

- `ProgressCompleted` 现在明确使用单向 WPF 绑定，窗口显示阶段不再因只读属性写入而终止。
- 新增真实窗口布局回归测试，可复现并防止该启动崩溃再次出现。

## 安装方式

运行 `FolderThemeStudio-v0.1.0-beta.3-setup.exe`。如果未检测到 x64 `.NET 8 Desktop Runtime`，安装器会从微软固定 HTTPS 地址下载 8.0.29 安装器、校验 SHA-256，再以 `/install /quiet /norestart` 安装。下载或校验失败会中止安装。

首次安装需要网络；安装 .NET 可能要求管理员授权或重启。共享运行时不会随应用卸载。安装器尚未代码签名。

## 验证限制

在线依赖安装仍需在没有 .NET 8 Desktop Runtime 的干净 Windows 10/11 虚拟机中人工验收。真实文件夹、用户注册表和 Shell 设置未被自动化测试修改。
