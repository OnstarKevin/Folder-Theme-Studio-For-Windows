# Folder Theme Studio v0.1.0-beta.6

## 新增

- 兼容模式可为指定根目录启用递归持久监控，之后新建的文件夹自动继承图标。
- 关闭主窗口默认转入系统托盘，托盘菜单可打开窗口、暂停/恢复监控或彻底退出。
- 默认在登录 Windows 后后台启动并恢复监控，可在设置中关闭。

## 修复

- 已有自定义文件夹现在可以再次修改。软件只替换 Desktop.ini 的图标字段，保留其他设置、注释、编码和换行格式。
- 应用前保存原 Desktop.ini 内容与属性；恢复时在安全条件满足时精确还原。

## 安装

运行 `FolderThemeStudio-v0.1.0-beta.6-setup.exe`。安装器会在需要时联网安装 x64 .NET 8 Desktop Runtime。

本版本未签名，请核对随附的 SHA-256 校验文件。
