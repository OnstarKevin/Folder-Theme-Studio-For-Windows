# 文件夹主题工坊使用教程

## 安装与启动

1. 运行 `FolderThemeStudio-v0.1.0-beta.8-setup.exe`。
2. 若电脑缺少 .NET 8 桌面运行时，请保持联网，让安装器自动安装。
3. 软件顶部可随时打开“使用教程”和“设置”；语言切换位于设置中。

## 使用可视化调色板

1. 在“图标来源”中选择“内置文件夹样式”。
2. 在“可视化调色板”选择渐变起始色、渐变结束色、边框颜色或发光颜色。
3. 直接在大色板中用鼠标选取饱和度和亮度，在右侧竖条选择色相；也可输入十六进制颜色。
4. 右侧会同步显示 16、32、64、256 px 预览。
5. 刚完成的编辑会立即成为当前图标，无需保存个人主题即可计算方案和应用；保存仅用于以后复用。

## 导入图片图标

1. 在“图标来源”中选择“导入图片图标”。
2. 点击“选择图片”，导入 PNG、JPG、JPEG、BMP 或 ICO；不支持 GIF。多尺寸 ICO 会自动采用最大分辨率图层。
3. 图片会作为完整图标使用，并自动保持比例、居中和补透明边距。
4. 确认预览后计算方案并应用。
5. 刚导入的图片或 ICO 会立即成为当前图标，不需要额外保存。

## 应用与恢复

- 全局模式统一修改当前用户的普通文件夹图标映射，不扫描整个磁盘。
- 兼容模式仅处理手动添加的根目录；已有自定义配置会安全合并，特殊、受保护或不可写文件夹仍会跳过。
- 勾选“让新文件夹继续使用此样式”后，软件会递归监控所选根目录，新建文件夹自动继承当前图标。
- 顶部打开“自动样式规则”，为已监控目录添加名称关键词与图标；可选当前编辑样式，也可导入图片或 ICO。
- 名称按“不区分大小写的包含匹配”判断；列表越靠前优先级越高。没有匹配时使用该根目录原有的监控图标。
- 规则递归覆盖所选根目录下之后新建的文件夹；重命名事件仍使用原有默认图标处理，不会批量改写已有文件夹。
- 顶部打开“文件夹分类卡片”，选择普通文件夹并填写分类、备注和两种渐变强调色后保存；在桌面或资源管理器文件列表中悬停约半秒即可查看。卡片固定在文件夹旁，不跟随鼠标移动，也不修改文件夹图标或内容。
- 默认在目标文件夹上按 Alt＋鼠标右键可直接打开同款编辑窗口；在设置中可以改成其他修饰键组合＋右键或中键。请先将光标短暂停在文件夹上，待目标识别完成；对非文件夹的右键仍保持 Windows 原有行为。
- 设置中的“不透明度”对所有备注卡片生效。分类数据保存在当前用户的本地应用配置中；文件夹被移动后需要重新为新路径添加分类。文件、快捷方式和虚拟项目不显示卡片。
- 关闭主窗口默认收起到托盘；可从托盘暂停/恢复监控或彻底退出。登录 Windows 后会自动在后台恢复监控，这两项可在“设置”关闭。
- 修改选项后必须重新“计算方案”，再点击“应用”。
- “恢复最近备份”可撤销最近一次应用。
- 主窗口、设置窗口和教程窗口会在受支持的 Windows 版本上使用原生圆角，并保留正常的标题栏、缩放与贴靠行为。

## 常见问题

- 双击无反应：安装 x64 `.NET 8 Desktop Runtime`，或重新联网运行安装器。
- 图标未立即刷新：等待 Windows 图标缓存刷新，或重新打开文件夹窗口。
- SmartScreen 警告：Beta 7 未签名，请从可信发布页下载并核对 SHA-256。
- 软件只替换普通文件夹图标，不替换文件资源管理器本身。
