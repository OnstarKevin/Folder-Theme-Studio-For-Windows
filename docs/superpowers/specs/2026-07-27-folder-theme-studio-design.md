# 文件夹主题工作室设计规范

## 目标

构建一款 Windows 原生桌面工具，让用户以可视化方式设计并应用普通文件夹图标。首个内置主题为“玻璃霓虹 / 冰川蓝”。工具仅改变普通文件夹图标，不修改文件资源管理器界面、不改变文件类型图标，也不覆盖桌面、下载、文档、图片等系统特殊文件夹的专用图标。

## 平台与交付形式

- 平台：Windows 10 与 Windows 11。
- 技术：.NET 8、WPF。
- 交付：可直接运行的桌面应用；发布阶段提供自包含版本，避免要求用户预装 .NET。
- 权限：优先在当前用户范围内工作。只有用户明确选择且操作确实需要时才请求提升权限。

## 产品结构

### 外观编辑器

用户可以调整：

- 两个渐变颜色与渐变方向；
- 整体透明度；
- 文件夹圆角；
- 描边颜色、透明度和粗细；
- 玻璃高光强度；
- 光晕颜色、强度与扩散范围；
- 阴影强度和偏移。

首个默认预设为“玻璃霓虹 / 冰川蓝”。参数变化必须立即反映在预览中。用户可以保存、重命名、删除、导出和导入自定义主题；内置主题不可被永久删除。

### 实时预览

预览区同时显示超大、大、中、小四种尺寸，并使用接近 Windows 浅色和深色背景的两种底色检查辨识度。预览必须使用与最终图标相同的绘制模型，避免界面预览与导出的 ICO 不一致。

### 应用管理

工具提供两种应用模式：

1. 全局快速模式：在当前用户范围备份并写入普通文件夹的 Shell 图标映射，然后通知 Windows Shell 刷新图标显示。该模式速度快，但依赖未正式文档化的 Windows 行为，界面必须明确说明系统更新后可能需要重新应用。
2. 兼容模式：只递归处理用户明确选择的本地目录，使用 Windows 支持的 `Desktop.ini` 机制为其中的普通文件夹设置图标。

全局快速模式失败时，只提供切换兼容模式的建议，不自动扫描磁盘。兼容模式必须在开始前显示所选根目录和预计范围，且不得默认选择整块磁盘。

### 恢复与记录

每次应用前保存可恢复快照，包括原 Shell 图标映射、生成的主题文件位置，以及工具对兼容模式目标所做的变更记录。

“恢复默认”应：

- 恢复或移除工具写入的 Shell 图标映射；
- 仅撤销由本工具创建或接管的兼容模式配置；
- 保留用户原本已有的 `Desktop.ini` 和自定义文件夹图标；
- 刷新 Shell 图标显示；
- 在部分恢复失败时展示具体路径和可执行的处理建议。

## 普通文件夹判定与排除

兼容模式仅处理本地文件系统中的普通目录。以下对象必须跳过：

- Windows 已知文件夹及其专用图标目标，包括桌面、下载、文档、图片、音乐、视频等；
- Windows、Program Files、ProgramData 等系统或应用目录；
- 网络路径、重解析点和符号链接；
- 无写入权限的目录；
- 已存在且并非由本工具管理的自定义图标配置；
- 用户在本次运行中明确排除的目录。

已知文件夹应通过 Windows Known Folder API 识别，并辅以规范化路径比较，不能只依赖中文或英文目录名。

## 图标生成

图标绘制器使用一套与分辨率无关的几何参数生成各尺寸图像，并将 16、20、24、32、48、64、128、256 像素的 PNG 帧封装为单个 ICO。小于或等于 32 像素的输出允许使用专门的小尺寸参数，减少过细描边、模糊高光和不可辨认的阴影。

生成的主题文件存放在当前用户的本地应用数据目录中，使用稳定主题标识命名。应用中的主题配置采用带版本号的 JSON 格式，未来字段增加时可迁移。

## 操作流程

1. 用户选择预设或调整参数。
2. 应用实时渲染各尺寸预览。
3. 用户选择全局快速模式或兼容模式。
4. 工具验证参数、目标范围与写入权限。
5. 工具生成 ICO 并验证所有必需尺寸。
6. 工具创建恢复快照。
7. 工具应用设置并通知 Windows Shell 刷新。
8. 界面显示成功、跳过和失败结果；失败项可复制或导出。

任何步骤失败时，不得声称应用成功。若失败发生在系统设置写入之后，工具应尝试回滚到本次操作前的快照，并报告回滚结果。

## 模块边界

- `ThemeModel`：主题参数、验证和版本迁移，不负责界面或文件写入。
- `FolderIconRenderer`：根据主题生成预览位图和 ICO，不负责应用系统设置。
- `KnownFolderService`：识别 Windows 特殊文件夹和受保护路径。
- `GlobalIconService`：备份、应用和恢复当前用户范围的快速模式设置。
- `CompatibleFolderService`：规划、应用和撤销兼容模式变更。
- `ShellRefreshService`：封装 Shell 变更通知，不直接修改主题。
- `BackupService`：持久化快照、变更清单和恢复状态。
- `ThemeStore`：保存、导入和导出主题 JSON。
- WPF 界面层：组织用户操作、进度和错误展示，不包含系统修改逻辑。

模块通过明确的数据对象传递计划、进度与结果。系统修改服务必须支持“仅规划”调用，使界面能在写入前展示目标范围。

## 错误处理与安全要求

- 所有路径先规范化，再检查是否属于允许范围。
- 不跟随重解析点，避免越过用户选择的目录边界。
- 原子写入主题、快照和工具管理的 `Desktop.ini`；写入失败时保留原文件。
- 对权限不足、文件占用、路径过长和 Shell 刷新失败分别给出可理解的提示。
- 兼容模式支持取消；取消后停止安排新目录，并完成当前原子操作。
- 日志不记录文件内容、用户名以外的个人信息或不必要的完整目录清单。用户主动导出报告时才包含失败路径。

## 测试与验收

### 自动测试

- 主题参数边界、JSON 往返和版本迁移；
- 所有 ICO 尺寸存在且可解码；
- 小尺寸绘制不越界；
- Known Folder 和规范化路径排除；
- 重解析点、无权限目录和已有自定义配置的跳过逻辑；
- 快照创建、部分失败回滚和恢复幂等性；
- 兼容模式只撤销工具拥有的变更；
- Shell 刷新调用及失败结果传播。

### 手工验收

- Windows 10 与 Windows 11 各验证一次全局快速模式、重新应用和恢复；
- 在浅色与深色主题、100% 与高 DPI 缩放下检查界面；
- 在列表、小图标、中图标、大图标和超大图标视图检查冰川蓝图标；
- 验证系统特殊文件夹和文件图标不变；
- Windows 重启及应用关闭后设置保持；
- Windows 更新导致快速模式失效时，重新应用或切换兼容模式的提示可用。

## 完成标准

用户可以从默认冰川蓝主题开始，高度自定义外观并保存主题；可以安全地将图标应用到普通文件夹；系统特殊文件夹、文件图标和文件资源管理器界面保持不变；工具可以准确报告失败并恢复到应用前状态。
