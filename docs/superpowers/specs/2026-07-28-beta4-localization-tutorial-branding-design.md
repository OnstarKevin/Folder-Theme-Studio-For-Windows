# Folder Theme Studio Beta4 设计规格

日期：2026-07-28

## 目标

在现有 WPF 应用中加入中英文界面、首次启动教程、顶部帮助与设置入口、文件夹图标可视化调色板，并统一应用新的文件夹魔法棒品牌 Logo。最终产出可由用户直接上传 GitHub 的 Beta4 安装包、源码包、说明文档与校验值。

## 技术方案

采用现有项目内集成方案，不引入大型本地化或主题框架：

- 使用中英文资源字典提供界面文本，并支持运行时切换。
- 使用当前用户配置保存语言、教程完成状态、调色板与最近颜色。
- 沿用现有图标生成、应用、恢复、缓存刷新和安装流程。
- 新功能以必要验证为主，不削弱已有注册表、恢复及下载校验保护。

## 界面

主窗口顶栏左侧显示新 Logo、中文名“文件夹主题工坊”和英文名“Folder Theme Studio”；右侧显示“使用教程”和“设置”按钮。

设置窗口包含：

1. “常规”：中文与 English 切换。
2. “图标调色板”：编辑渐变起始色、渐变结束色、描边色和光晕色；提供 HSV/十六进制选色、推荐颜色、最近颜色及文件夹实时预览，并带保存与取消操作。

调色板仅控制生成的普通文件夹图标，不改变应用界面主题。

## 教程

首次启动自动显示分步教程，覆盖选择样式、调整配色、预览、应用和恢复。完成或跳过后记录状态；用户可通过顶栏“使用教程”随时重新打开。

## 品牌资源

Logo 采用简洁线框文件夹配魔法棒/星光造型，制作可缩放源文件及多尺寸 PNG、ICO，并统一应用于窗口、任务栏、EXE、安装程序和项目文档。

## 数据与行为

- 设置保存在当前用户范围，重启后保持。
- 合法颜色保存后立即刷新预览和后续图标生成结果。
- 无效颜色输入阻止保存，并显示简短的本地化提示。
- 正式应用颜色时继续使用现有安全写入、恢复点与资源刷新流程。

## 验证与发布

重点验证中英文切换、配置持久化、颜色生成、教程首次显示、窗口真实启动及安装流程。版本升级为 Beta4，并输出：

- 框架依赖型在线安装包；
- GitHub 可上传源码包；
- 中英文 README/使用教程、发布说明与 SHA-256 校验值。

不在本任务中代替用户推送远程仓库或创建 GitHub Release。
