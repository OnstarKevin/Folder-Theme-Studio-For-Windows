# Folder Theme Studio 可视化调色板与图片图标导入设计

## 目标

为 Folder Theme Studio 增加两个互相独立的图标来源：现有内置文件夹设计，以及用户导入的静态图片。内置设计获得真正可用鼠标直接选择颜色的二维调色板；图片导入直接生成完整文件夹图标。

本次不实现“计算方案”进度条，也不支持 GIF 或其他动画格式。

## 界面与交互

主窗口的图标编辑区顶部使用同页双模式切换：

1. **内置文件夹设计**：保留渐变、描边、发光和现有高级参数。颜色区域提供颜色角色列表、二维饱和度/明度面板、色相条、选色指示器、当前颜色块和十六进制辅助输入。鼠标点击或拖动立即更新当前角色、数值和文件夹预览。
2. **导入图片图标**：独立显示选择图片、更换图片、清除图片和最终图标预览。该模式不显示内置文件夹参数或调色板。

设置窗口保留语言等通用设置。颜色编辑从设置窗口迁移至主窗口的内置设计模式，避免入口重复和用户误认为十六进制输入就是调色板。

## 支持格式与图像布局

- 支持 PNG、JPG/JPEG 和 BMP。
- 不显示或接受 GIF。
- 图片作为完整图标，不叠加在内置文件夹造型上。
- 保持原始宽高比，不裁剪；在透明正方形画布中居中并透明留边。
- 保留 PNG 透明通道；不透明格式的图像内容保持原样，周围画布透明。
- 生成 Windows 文件夹图标所需的多尺寸 ICO 帧，覆盖现有渲染器要求的 16–256 像素尺寸。

## 状态模型与数据流

新增明确的图标来源状态 `BuiltIn` 和 `ImportedImage`。应用请求与应用方案携带不可混淆的图标来源描述：内置来源引用当前 `FolderTheme`，图片来源引用已规范化的本地图片资产。

用户选择图片后，程序先完整解码并验证，再将其规范化为保留透明度的本地资产，保存到 `%LocalAppData%\FolderThemeStudio\imports`。只有写入和重新读取成功后才替换当前有效选择；原始文件之后移动或删除不影响应用。

预览和最终 ICO 使用同一套图片布局逻辑。应用阶段根据来源选择内置渲染器或图片图标渲染器，再沿用现有全局模式、兼容模式、快照、恢复和 Shell 刷新流程。

切换图标来源、修改内置颜色或更换导入图片都会增加输入版本并使已审核方案失效，用户必须重新计算方案。保存主题仍只管理内置主题参数，导入图片不混入主题列表。

## 组件边界

- `VisualColorPicker`：把二维面板和色相条中的坐标转换为 HSV/RGB，维护指示器和颜色绑定；不负责保存主题。
- `ImportedImageService`：验证格式、解码图片、规范化并持久化导入资产；不负责生成 Windows 配置。
- `ImportedIconRenderer`：按保持比例、透明留边规则输出指定尺寸位图；不访问文件选择器或系统注册表。
- 图标产物服务：根据图标来源调用内置或图片渲染器并编码 ICO。
- 主视图模型：管理模式切换、预览、命令状态和方案失效，不实现图像算法。

## 错误处理

- 文件选择器只列出受支持格式。
- 损坏、空文件、扩展名与内容不匹配或无法解码时显示本地化错误，并保留上一个有效选择。
- 导入资产写入或回读失败时不更新当前图标来源。
- 图片模式尚未选择有效图片时禁止计算和应用，并显示明确提示。
- 内置模式继续使用现有主题验证规则。

## 测试与验收

- 用手工推导的固定值测试二维坐标与 HSV/RGB 转换边界和中间点。
- 测试四个颜色角色、十六进制辅助输入和实时预览联动。
- 测试模式切换、图片更换和颜色修改均使旧方案失效。
- 使用真实小型 PNG、JPEG 和 BMP 样本测试解码、透明度、比例保持、透明留边和多尺寸 ICO。
- 测试损坏或不支持的文件不会覆盖上一个有效导入。
- 测试图片来源通过现有全局与兼容应用流程，恢复数据模型保持兼容。
- 运行完整自动测试、Release 构建、安装包生成和 SHA-256 校验。

验收结果应表现为：用户能用鼠标在二维调色板上凭视觉选色；内置设计和图片导入入口清晰分离；导入的静态图片能以完整、不裁剪的形式成为 Windows 文件夹图标。
